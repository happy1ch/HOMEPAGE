행복한교회 설교 도구

시행일: 2026년 9월 23일

1. 이 도구는 무엇인가요

「설교 도구」는 행복한교회(경북 문경)가 자체 설교 영상을 정리하기 위해 교회 컴퓨터에서만 사용하는 프로그램입니다. 설교 영상과 자막을 교회 유튜브 채널(@happy1ch)에 올리고, 주보와 설교 기록을 교회의 구글 시트·드라이브에 정리합니다. 일반 사용자에게 제공하는 서비스가 아닙니다.

2. 사용하는 Google 데이터

  • YouTube: 교회 채널에 영상·자막을 올리고, 제목·재생목록을 정리하며, 채널 영상 목록을 읽습니다.
  • Google 시트: 교회 설교 기록 시트에 설교 정보를 적습니다.
  • Google 드라이브: 교회 문서를 읽어 컴퓨터에 사본을 만듭니다(읽기 전용).

이 권한은 교회 계정에 대해서만 쓰이며, 다른 사람의 계정이나 데이터에는 접근하지 않습니다.

3. 보관과 공유

  • 로그인 정보와 작업 파일은 교회 컴퓨터에만 저장되며, 외부 서버로 보내지 않습니다.
  • Google에서 받은 데이터를 판매하거나 광고에 쓰거나 제3자와 공유하지 않습니다.
  • Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회

Google 계정 → 보안 → 타사 앱 액세스에서 언제든 이 도구의 접근 권한을 해제할 수 있습니다.
